# 🍑 2026 복숭아 달력

날짜별 할 일을 가볍게 기록하고 관리할 수 있는 2026년 전용 달력 웹 서비스입니다.

연한 코랄 컬러와 프리텐다드 폰트를 사용해 따뜻하고 편안한 분위기로 디자인했으며, 배경에는 복숭아 이모지가 천천히 떠다닙니다.

## 서비스 바로가기

[2026 복숭아 달력 사용하기](https://peach-calendar-2026.hyhy425.chatgpt.site)

> 현재 사이트는 비공개로 게시되어 있어 접속 시 ChatGPT 로그인이 필요합니다.

## 주요 기능

- 2026년 1월부터 12월까지 월별 달력 보기
- 날짜를 선택해 할 일 추가
- 할 일 완료 및 삭제
- 전체, 할 일, 완료 상태별 필터
- 날짜별 할 일 개수와 완료 여부 표시
- 전체 할 일의 연간 완료율 확인
- 브라우저 자동 저장
- 데스크톱과 모바일에 대응하는 반응형 화면
- 움직임 최소화 설정 지원

## 디자인 특징

- 프리텐다드 폰트 사용
- 연한 코랄 중심의 따뜻한 색상 구성
- 복숭아 이모지와 CSS 애니메이션을 활용한 배경 효과
- 불필요한 이미지 및 SVG 장식 미사용
- 키보드 포커스와 스크린 리더용 레이블 적용

## 사용 방법

1. 달력에서 원하는 날짜를 선택합니다.
2. 오른쪽 또는 하단의 입력창에 할 일을 작성합니다.
3. `+` 버튼을 누르거나 Enter 키를 눌러 추가합니다.
4. 체크박스로 완료 상태를 변경합니다.
5. `전체`, `할 일`, `완료` 버튼으로 목록을 필터링합니다.

작성한 내용은 현재 브라우저의 로컬 저장소에 자동으로 저장됩니다. 다른 브라우저나 기기와는 동기화되지 않으며, 브라우저 데이터를 삭제하면 함께 사라질 수 있습니다.

## 기술 구성

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Pretendard Web Font

별도의 프레임워크나 빌드 과정 없이 정적 파일만으로 동작합니다.

## 로컬 실행

프로젝트의 `dist` 폴더를 정적 웹 서버로 실행한 뒤 브라우저에서 접속합니다.

Node.js 환경에서는 원하는 정적 서버 도구를 사용할 수 있습니다.

```bash
npx serve dist
```

## 파일 구조

```text
.
├─ dist/
│  ├─ index.html   # 화면 구조
│  ├─ styles.css   # 테마, 레이아웃, 반응형 스타일
│  └─ app.js       # 달력 생성과 할 일 관리 기능
└─ README.md
```

## 데이터 저장

할 일 데이터는 서버가 아닌 사용자의 브라우저 `localStorage`에 저장됩니다. 따라서 별도의 회원가입이나 데이터베이스 없이 사용할 수 있습니다.
